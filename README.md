# Meanders.Tools

Meanders.Tools is a Grasshopper plugin for Rhino focused on design, fabrication, geometry, data, and workflow utilities.

## Project Goals

- Build reusable Grasshopper tools for internal design workflows
- Maintain consistent component naming and behavior
- Provide complete component documentation
- Support long-term development and versioning
- Provide a reliable internal distribution workflow

## Repository Structure

- `Meanders.Tools/` — Grasshopper plugin source code
- `metadata/` — Component and plugin metadata
- `docs/` — Documentation source
- `ROADMAP.md` — Development roadmap
- `CHANGELOG.md` — Release history

## Current Status

Early development.
